1. The problem

Face swapping replaces the identity of a face in a target image or video with the identity from a source image, while keeping the target's pose, expression, lighting and background intact. The core challenge is disentangling identity from attributes: the swapped face should look like the source person, but with the target person's expression and head orientation.

Early GAN-based methods such as FaceShifter and SimSwap solved this with large monolithic generators. They produce high-quality results, but the full generator is expensive at inference and hard to adapt. This project takes the SimSwap architecture and decomposes it into three separate modules — an encoder, an AdaIN bottleneck, and a decoder — trained via knowledge distillation from the original monolithic generator. The result is a modular pipeline where each stage can be swapped, fine-tuned, or compressed independently.

2. The approach

The original SimSwap generator (Generator_Adain_Upsample) is a single U-Net-style network: it encodes the target face, injects the source identity through AdaIN layers in the bottleneck, and decodes the swapped result. The key idea here is to split this into three independently trainable components:

  1. Encoder — downsamples the target face from 224×224 to a 512-channel feature map at 28×28
  2. Bottleneck (BN_layer) — five ResNet blocks with Adaptive Instance Normalisation (AdaIN), where the source identity vector modulates the target features
  3. Decoder — upsamples back to 224×224 RGB

Each component is trained to match the corresponding intermediate outputs of the full teacher model, using knowledge distillation. This means the student encoder must produce the same latent as the teacher's encoder path, and so on.

Key insight

Decomposition via distillation is not about compression here — it is about modularity. Once trained, you can replace the decoder with a higher-resolution variant, swap the identity network, or add post-processing stages, all without retraining the full pipeline.

3. Full pipeline

At inference time, a single call to SimSwap.__call__ runs this sequence:

Source image → SCRFD detect → FFHQ align → ArcFace ID → Encoder → BN (AdaIN) → Decoder → BiSeNet mask → Soft erosion → Warp back → Blend

The blue stages are the core generator, decomposed from SimSwap. The surrounding stages handle face detection (SCRFD), alignment to FFHQ landmarks, identity extraction (ArcFace IR-SE50), face parsing (BiSeNet) for masking, and affine warp-back to place the swapped face into the original frame.

SimSwap.__call__ — the full forward pass

def __call__(self, att_image):
    # Extract source identity (once, cached after first call)
    if self.id_latent is None:
        align_id_imgs, _, _ = self.run_detect_align(self.id_image, for_id=True)
        src112 = F.interpolate(self.to_tensor(align_id_imgs[0]).unsqueeze(0), (112, 112))
        self.id_latent, _ = self.face_id_net(src112)
        self.id_latent = F.normalize(self.id_latent, p=2, dim=1)

    # Detect & align all faces in the target
    align_att_imgs, att_transforms, _ = self.run_detect_align(att_image)

    # Core swap: Encoder → Bottleneck (with identity injection) → Decoder
    tgt224 = self.to_tensor(align_att_imgs[0]).unsqueeze(0)
    target_latent = self.encoder_(tgt224)
    target_latent = self.bottleneck_(target_latent, self.id_latent)
    swapped_img = self.simswap_net(target_latent)

    # Get face mask from BiSeNet, apply soft erosion
    face_mask, ignore_mask_ids = self.bise_net.get_mask(...)
    soft_face_mask, _ = self.smooth_mask(face_mask)

    # Warp swapped face back and blend with original frame
    return soft_face_mask * target_image + (1 - soft_face_mask) * att_image

4. Identity extraction with ArcFace

The source face's identity is encoded by an ArcFace model (IR-SE50 architecture with Squeeze-and-Excitation blocks). The aligned source face is resized to 112×112 and passed through the network, producing a 512-dimensional embedding that captures identity-specific features — face shape, eye spacing, nose structure — while being invariant to expression and pose.

ArcFace identity encoding — ResNet with IR blocks

class ResNet(nn.Module):
    def __init__(self, block, layers, use_se=True):
        self.conv1 = nn.Conv2d(3, 64, kernel_size=3, stride=1)
        self.layer1 = self._make_layer(block, 64,  layers[0])  # 3 blocks
        self.layer2 = self._make_layer(block, 128, layers[1], stride=2)  # 4 blocks
        self.layer3 = self._make_layer(block, 256, layers[2], stride=2)  # 23 blocks
        self.layer4 = self._make_layer(block, 512, layers[3], stride=2)  # 3 blocks
        self.fc = nn.Linear(512 * 7 * 7, 512)  # → 512-d embedding

Each IRBlock uses a BN → Conv → BN → PReLU → Conv → BN → SE structure. The SE (Squeeze-and-Excitation) block recalibrates channel responses by learning channel-wise attention weights via a small FC bottleneck.

SE block — channel attention

class SEBlock(nn.Module):
    def forward(self, x):
        b, c, _, _ = x.size()
        y = self.avg_pool(x).view(b, c)         # global average pool → (B, C)
        y = self.fc(y).view(b, c, 1, 1)         # FC → sigmoid → (B, C, 1, 1)
        return x * y                              # channel-wise reweighting

The resulting 512-d vector is L2-normalised before being fed to the bottleneck's AdaIN layers.

5. Generator architecture: Encoder → Bottleneck → Decoder

5.1 Encoder

The encoder takes a 224×224 target face crop and produces a 512-channel spatial feature map at 28×28 resolution through three strided convolution blocks, each followed by BatchNorm and ReLU:

# 224×224×3 → 224×224×64 → 112×112×128 → 56×56×256 → 28×28×512
class Encoder(nn.Module):
    def __init__(self, input_nc=3, output_nc=3, latent_size=512):
        self.first_layer = nn.Sequential(ReflectionPad2d(3), Conv2d(3, 64, 7), BN, ReLU)
        self.down1 = nn.Sequential(Conv2d(64,  128, 3, stride=2), BN, ReLU)
        self.down2 = nn.Sequential(Conv2d(128, 256, 3, stride=2), BN, ReLU)
        self.down3 = nn.Sequential(Conv2d(256, 512, 3, stride=2), BN, ReLU)

5.2 Bottleneck — AdaIN identity injection

The bottleneck is where identity transfer happens. It consists of five ResnetBlock_Adain blocks. Each block applies two convolutions with Instance Normalisation, and after each conv the ApplyStyle module modulates the features using the source identity vector:

AdaIN y = (sscale + 1) · InstanceNorm(x) + sshift , where [sscale, sshift] = Linear(zid)

The 512-d identity vector zid is projected through a linear layer to produce per-channel scale and shift parameters. This is exactly the mechanism from StyleGAN's style injection — but here the "style" is a face identity embedding rather than a random latent code.

ApplyStyle — the AdaIN operation

class ApplyStyle(nn.Module):
    def __init__(self, latent_size, channels):
        self.linear = nn.Linear(latent_size, channels * 2)  # scale + shift

    def forward(self, x, latent):
        style = self.linear(latent)                # (B, C×2)
        style = style.view(-1, 2, x.size(1), 1, 1)  # (B, 2, C, 1, 1)
        x = x * (style[:, 0] + 1.0) + style[:, 1]  # scale & shift
        return x

Each ResNet-AdaIN block has two such injections (after each conv), so five blocks means ten identity modulations total. This repeated injection ensures the identity signal is deeply woven into the feature representation.

5.3 Decoder

The decoder mirrors the encoder: three bilinear-upsample + Conv + BN + ReLU blocks, followed by a ReflectionPad + Conv + Tanh final layer that outputs a 224×224 RGB image in [0, 1]:

# 28×28×512 → 56×56×256 → 112×112×128 → 224×224×64 → 224×224×3
class Decoder(nn.Module):
    def forward(self, x):
        x = self.up3(x)        # 512 → 256, ×2 upsample
        x = self.up2(x)        # 256 → 128, ×2 upsample
        x = self.up1(x)        # 128 → 64,  ×2 upsample
        x = self.last_layer(x) # 64  → 3,   Tanh
        x = (x + 1) / 2       # [-1,1] → [0,1]
        return x

6. Knowledge distillation

The original SimSwap generator (Generator_Adain_Upsample) is the teacher. It has the same encoder–bottleneck–decoder structure but as a single monolithic network with six AdaIN ResNet blocks. The student models are the three separate modules described above.

Training proceeds in three stages:

  1. Encoder distillation — the student encoder is trained to minimise the L2 distance between its output and the teacher encoder's output (the feature map after down3) for the same input
  2. Bottleneck distillation — with the student encoder frozen, the student bottleneck is trained to match the teacher bottleneck's output given the same encoder features and identity vector
  3. Decoder distillation — with encoder and bottleneck frozen, the student decoder is trained to match the teacher's RGB output from the same bottleneck features
Why not end-to-end?

Stage-wise distillation is simpler to debug — if the decoder's output is wrong, you know the bottleneck features are correct (they were frozen and already validated), so the problem is in the decoder alone. It also allows mixing-and-matching: a decoder trained on higher resolution data can be dropped in without retraining the encoder or bottleneck.

The teacher model (Encoder_Real) uses the full SimSwap weights from simswap_224_latest_net_G.pth (210 MB) with 9 AdaIN ResNet blocks, while the student bottleneck uses only 5 blocks — a 44% reduction. The teacher was originally trained on the VGGFace2 dataset at 224×224 resolution.

Teacher model — full SimSwap loaded as Encoder_Real

# Teacher: 9 AdaIN blocks, 210 MB
encoder_real = Encoder_Real(input_nc=3, output_nc=3, latent_size=512, n_blocks=9).to(device)
encoder_real.load_state_dict(torch.load("./weights/simswap_224_latest_net_G.pth"))
encoder_real.eval()

# Student: separate Encoder (frozen) + BN_layer (5 blocks, trainable) + Decoder (frozen)
encoder_ = Encoder(input_nc=3, output_nc=3, latent_size=512).to(device)
bottleneck_ = BN_layer(n_blocks=5).to(device)
decoder_ = Decoder().to(device)

# Only the bottleneck is optimised
optimizer_BN = torch.optim.Adam(bottleneck_.parameters(), lr=0.004, betas=(0.0, 0.999))
Model size

The full SimSwap teacher is 210 MB. The distilled student (encoder + bottleneck + decoder combined) is 122 MB — a 42% reduction in model size, with the bottleneck reduced from 9 to 5 AdaIN blocks.

7. Loss functions

The bottleneck is trained with a composite loss of seven terms. Each term targets a different aspect of fidelity — pixel-level accuracy, latent-space alignment, identity preservation, feature matching, and perceptual similarity. The teacher model produces the ground-truth targets; the student must match them.

7.1 Knowledge distillation response loss (L1)

The primary distillation signal. L1 (mean absolute error) between the teacher's swapped output and the student's swapped output, pixel by pixel:

L1 ℒKD = | Iteacher − Istudent |1 
# Teacher swap: target through full Encoder_Real
swap_latent = encoder_real(tgt_tensor, face_id_src)
swap_img = decoder_(swap_latent)

# Student swap: target through Encoder → Bottleneck → Decoder
target_latent = encoder_(tgt_tensor)
target_latent = bottleneck_(target_latent.detach(), face_id_src)
pred_swap = decoder_(target_latent)

# L1: pixel-level match between teacher and student outputs
l1 = F.l1_loss(swap_img.detach(), pred_swap)

7.2 Latent loss (L2)

MSE between the teacher's bottleneck feature map and the student's, computed channel-by-channel across the 512 channels of the 28×28 spatial map. This forces the student bottleneck to produce the same internal representation as the teacher:

L2 ℒlatent = Σb,c MSE( Fteacher[b, c], Fstudent[b, c] ) 
# L2: latent space alignment (512 channels × 28×28)
l2 = 0.0
for b in range(batch_size):
    for i in range(512):
        l2 += F.mse_loss(swap_latent[b][i,:,:].detach(), target_latent[b][i,:,:])

7.3 Source identity loss (L3)

The swapped face should look like the source person. This is measured by cosine similarity between the source identity embedding and the identity embedding extracted from the student's output:

L3 ℒsrc-id = 1 − cos( zsource, zstudent-swap ) 
def cosin_metric(x1, x2):
    return torch.sum(x1 * x2, dim=1) / (torch.norm(x1, dim=1) * torch.norm(x2, dim=1))

# L3: student swap should match source identity
face_id_swap_pred, feat_swap_pred = arcnet(F.interpolate(pred_swap, (112, 112)))
face_id_swap_pred = F.normalize(face_id_swap_pred, p=2, dim=1)
l3 = (1.0 - cosin_metric(face_id_src, face_id_swap_pred)).mean()

7.4 Swap identity loss (L4)

The student's output should also match the teacher's output in identity space — i.e. the teacher and student swaps should represent the same person:

L4 ℒswap-id = 1 − cos( zteacher-swap, zstudent-swap ) 
# L4: student swap identity should match teacher swap identity
face_id_swap_act, _ = arcnet(F.interpolate(swap_img, (112, 112)))
face_id_swap_act = F.normalize(face_id_swap_act, p=2, dim=1)
l4 = (1.0 - cosin_metric(face_id_swap_act.detach(), face_id_swap_pred)).mean()

7.5 Source feature loss (L5)

Beyond the final identity vector, the intermediate ArcFace feature maps also carry structural information. L5 matches the ArcFace feature maps (from all 4 residual stages) between the source face and the student's swap, pushing the student to preserve source-like features at every spatial scale:

# L5: multi-scale ArcFace feature matching (source → student swap)
# feat_src and feat_swap_pred are lists of feature maps from 4 ResNet stages
l5 = 0.0
for b in range(batch_size):
    for c in range(len(feat_src)):
        for j in range(feat_src[c].shape[1]):
            l5 += F.mse_loss(feat_src[c][b][j].detach(), feat_swap_pred[c][b][j])

7.6 Swap feature loss (L6)

Similarly, the ArcFace feature maps from the student's swap should match those from the teacher's swap — ensuring structural consistency between teacher and student at every intermediate layer:

# L6: multi-scale ArcFace feature matching (teacher swap → student swap)
l6 = 0.0
for b in range(batch_size):
    for c in range(len(feat_swap_act)):
        for j in range(feat_swap_act[c].shape[1]):
            l6 += F.mse_loss(feat_swap_act[c][b][j].detach(), feat_swap_pred[c][b][j])

7.7 Perceptual loss — LPIPS (L7)

LPIPS (Learned Perceptual Image Patch Similarity) using a VGG-16 backbone measures high-level perceptual similarity between teacher and student outputs. Unlike pixel-level L1, LPIPS captures structural and textural differences that align with human perception:

L7 ℒLPIPS = 1 − LPIPS( Iteacher, Istudent ) 
lpips = piqa.LPIPS(network="vgg").to(device)
l7 = 1.0 - lpips(swap_img.detach(), pred_swap)

7.8 Total loss

The seven terms are combined with hand-tuned weights. The KD response loss gets weight 8, while identity, feature matching and perceptual losses each get weight 10. The latent loss is unweighted (its natural magnitude is already large due to summing over 512 channels):

Total ℒ = 8 · ℒKD + ℒlatent + 10 · ℒsrc-id + 10 · ℒswap-id + 10 · ℒsrc-feat + 10 · ℒswap-feat + 10 · ℒLPIPS 
loss = l1*8.0 + l2 + l3*10.0 + l4*10.0 + l5*10.0 + l6*10.0 + l7*10.0
LossWhat it measuresWeight
L1 — KD responsePixel-level match (teacher vs student output)8.0
L2 — LatentBottleneck feature map alignment (512 × 28 × 28)1.0
L3 — Source IDSource identity preserved in swap (cosine)10.0
L4 — Swap IDStudent matches teacher identity (cosine)10.0

Design rationale

The loss design has two layers of supervision: output-level (L1 pixel match, L7 perceptual) and representation-level (L2 latent, L3–L6 identity and features). The identity losses (L3, L4) prevent the student from producing faces that look plausible but belong to the wrong person. The feature losses (L5, L6) add multi-scale structural constraints that neither pixel nor identity losses alone capture.

8. Face parsing and blending

After the generator produces a swapped face crop, it needs to be placed back into the original frame. This is a two-step process:

8.1 Face parsing with BiSeNet

A BiSeNet (Bilateral Segmentation Network) model segments the aligned face into 19 semantic regions (skin, eyes, nose, lips, hair, etc.). The face mask includes regions [1, 2, 3, 4, 5, 6, 10, 12, 13] — covering skin, eyebrows, eyes, nose, upper/lower lip, and ears — while excluding the neck, hair, and background.

Face parsing to binary mask

face_part_ids = [1, 2, 3, 4, 5, 6, 10, 12, 13]
for valid_id in face_part_ids:
    face_map[parse == valid_id] = 255

8.2 Soft erosion

The binary mask has hard edges that would create visible seams when composited. A SoftErosion module smooths the mask boundary by convolving with a distance-weighted kernel, then thresholding:

class SoftErosion(nn.Module):
    def __init__(self, kernel_size=15, threshold=0.6, iterations=1):
        # Build distance-weighted kernel
        dist = sqrt((x - r)² + (y - r)²)
        kernel = dist.max() - dist
        kernel /= kernel.sum()

    def forward(self, x):
        for i in range(self.iterations - 1):
            x = min(x, conv2d(x, kernel))     # iterative erosion
        x = conv2d(x, kernel)                  # final smooth pass
        x[x >= threshold] = 1.0               # hard inside
        x[x < threshold] /= x[x < threshold].max()  # soft boundary
        return x

8.3 Affine warp-back and alpha blend

The swapped face and soft mask are warped back to the original frame using the inverse of the alignment affine transform, then composited with standard alpha blending:

result = Msoft · Iswap + (1 − Msoft) · Itarget

Kornia's warp_affine handles the inverse transform with bilinear interpolation and border padding, keeping the blending differentiable end-to-end.

Training loop — bottleneck distillation with 7 losses

for epoch in range(0, 500000):
    bottleneck_.train()
    src_tensor, tgt_tensor, _ = getdata(batch_size, train_images, device)

    # ArcFace source identity
    src112 = F.interpolate(src_tensor, (112, 112))
    face_id_src, feat_src = arcnet(src112)
    face_id_src = F.normalize(face_id_src, p=2, dim=1)

    # Teacher forward pass (frozen)
    swap_latent = encoder_real(tgt_tensor, face_id_src)
    swap_img = decoder_(swap_latent)

    # Student forward pass (only bottleneck trainable)
    target_latent = encoder_(tgt_tensor)
    target_latent = bottleneck_(target_latent.detach(), face_id_src)
    pred_swap = decoder_(target_latent)

    # All 7 losses computed, weighted sum
    loss = l1*8.0 + l2 + l3*10.0 + l4*10.0 + l5*10.0 + l6*10.0 + l7*10.0

    optimizer_BN.zero_grad()
    loss.backward()
    optimizer_BN.step()
Training note

Only the bottleneck's parameters are optimised. The encoder, decoder, ArcFace, and teacher model are all frozen. At every 50 steps, evaluation images are saved showing source → target → teacher swap → student swap side by side.

10. Results

Training was run for 500k iterations on a single GPU. The evaluation saves a grid of 8 images at every 50 steps, showing four rows: source face, target face, teacher (SimSwap) output, and student output.

12. Takeaways

  • Modular decomposition via distillation makes the pipeline practical to iterate on. Each component (encoder, bottleneck, decoder) can be improved independently without retraining the full generator.
  • AdaIN is the identity transfer mechanism — the source face's 512-d embedding modulates feature statistics at every ResNet block in the bottleneck. Ten injections across five blocks ensure strong identity transfer.
  • The surrounding pipeline matters as much as the generator. Face detection quality, alignment accuracy, face parsing precision, and soft-mask parameters all directly affect the final output quality. The generator only produces a 224×224 crop — everything else is geometry and compositing.
  • Soft erosion for seamless blending is a simple but effective technique. The distance-weighted kernel produces a natural gradient at face boundaries, avoiding the hard-edge artifacts of binary masking.
